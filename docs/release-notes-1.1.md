# 핫딜 수집 관리자 1.1.0

관심 품목 필터와 새 글 표시, 넓어진 화면, 별도 로그 창, 자동 업데이트 기능을 추가한 Windows x64 릴리즈입니다.

## 설치

Assets에서 **HotdealCollector-Setup-1.1.0-x64.exe**를 내려받아 설치하세요. Google Chrome이 필요하며 Node.js는 별도로 설치하지 않아도 됩니다.

**1.0.0은 자동 업데이트를 지원하지 않으므로 트레이에서 앱을 완전히 종료하고 1.1.0 설치 파일을 한 번 직접 실행하세요.** 기존 설치 위치를 사용하면 `%APPDATA%\HotdealCollector`의 게시글·설정을 유지합니다. 설치 후 Windows 자동 실행 설정을 확인하세요.

## 추가 및 개선

- 관심 품목 키워드 등록, 관심 품목만 목록 보기, 관심 품목 새 글만 알림.
- 최근 새 글 묶음에 **New** 태그 표시와 자동 갱신.
- 서버 제어·수집 상태를 작은 공통 패널로 통합하고 게시글 목록 확대.
- 설정을 넓은 카드 배치로 정리하고 **실행 로그 열기**로 별도 실시간 로그 창 제공.
- 타이틀 아래 **현재 앱 버전** 표시.
- 시작 시와 6시간마다 공개 GitHub 릴리즈 확인. 새 버전이 있을 때만 **업데이트** 버튼 표시.
- 버튼으로 업데이트 다운로드 후 **재시작 및 설치**. 서버와 전용 Chrome을 정상 종료한 뒤 설치하며, 데이터는 유지. 재실행 후 **서버 시작**으로 수집 재개.

다운로드 중 수집은 계속됩니다. 다운로드 또는 서버 종료에 실패하면 현재 앱을 유지하고 재시도할 수 있습니다. 일반 종료만으로 강제 업데이트하지 않습니다.

## 검증 및 배포 파일

- 자동 테스트 88개 통과.
- 설치 파일에 개인 `.env`·`.local` 데이터가 포함되지 않았는지 패키징 검사.
- 업데이트 메타데이터 버전·파일 크기·SHA-512 검증.
- 파일 검증용 `SHA256SUMS.txt`, 자동 업데이트용 `latest.yml` 및 `.blockmap`, 한국어 사용 안내서 제공.

현재 설치 파일에는 코드 서명이 없어 Windows에서 게시자 확인 안내가 나타날 수 있습니다. 수집은 첫 페이지의 주기적 확인이며 사이트 접속 정책·HTML 구조에 영향을 받습니다. 실패 시 마지막 정상 JSON을 유지합니다. 아카라이브 공식 앱이 아닙니다.
