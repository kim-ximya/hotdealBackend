# 관심 품목

앱 상단의 **관심 품목** 탭에서 원하는 상품의 키워드를 하나씩 입력하고 **등록**을 누릅니다. 등록된 키워드 옆의 **×**로 삭제할 수 있습니다. 최대 100개, 품목당 최대 80자이며 변경 즉시 저장됩니다.

게시글 **제목**에 등록한 키워드가 **하나라도 포함**되면 일치합니다. 영문 대소문자, 전각·반각 문자, 연속 공백은 정규화하여 비교합니다. 예를 들어 `SSD`는 `ssd 2TB`에도 일치합니다. 여러 단어를 입력하면 하나의 문구로 비교하며, 정규식이나 쉼표로 여러 품목을 한꺼번에 입력하는 방식은 지원하지 않습니다. 작성자·분류·본문은 검사하지 않습니다.

**등록한 관심 품목의 새 글만 알림**을 켜면 이후 감지한 새 글 중 일치하는 글만 플로팅 알림과 소리로 안내합니다. 끄면 전체 새 글 알림으로 돌아갑니다. 전체 알림·소리의 켜기/끄기는 기존 **설정 → 알림**을 따릅니다.

- 관심 품목만 알림을 켜고 등록 품목이 없으면 자동 새 글 알림을 보내지 않습니다.
- 설정 변경은 서버 재시작 없이 적용됩니다. 이미 떠 있던 알림은 닫습니다.
- 품목을 추가하거나 필터를 해제해도 이미 확인한 과거 글을 새 글로 다시 알리지 않습니다.
- 테스트 알림은 관심 품목 필터와 관계없이 미리보기를 표시합니다.
- 설정 파일을 읽지 못하면 기존 파일을 보존하고 자동 새 글 알림을 차단하며 오류를 표시합니다. 품목을 다시 등록해 복구할 수 있습니다.

**핫딜 목록 → 관심 품목만 보기**를 체크하면 전체 저장 글에서 일치하는 게시글만 최신순으로 표시합니다. 필터링 후 50개씩 페이지를 나누므로 이전 페이지에 있는 관심 품목도 조회할 수 있습니다. 등록된 품목이 없거나 일치하는 글이 없으면 빈 목록 안내를 표시합니다. 체크를 해제하면 전체 목록을 볼 수 있습니다.

이 기능은 알림과 표시 범위를 조절합니다. 수집한 전체 게시글은 계속 저장하며, 목록 필터 변경이나 새로고침은 사이트 크롤링을 추가 실행하지 않습니다. 별도로 실행 중인 기존 서버에 연결해도 저장 목록을 조회하여 필터링합니다. 여러 API 페이지를 조회하는 도중 수집 결과가 바뀌면 혼합된 결과 대신 오류를 표시하므로 목록을 새로고침하세요.

품목과 알림 범위는 앱 데이터 폴더의 `interest-settings.json`에 저장되어 재시작 후에도 유지됩니다.

- 개발판: `.local/desktop/interest-settings.json`
- 설치판: `%APPDATA%\HotdealCollector\interest-settings.json`

기존 1.0 설정 파일은 그대로 사용할 수 있습니다. 관심 품목 설정 파일이 없는 첫 실행은 등록 품목 없음·전체 새 글 알림으로 시작합니다. 목록의 보기 체크 상태는 앱을 다시 열면 전체 보기로 시작합니다.
